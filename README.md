# ClickFlare API Integration

A TypeScript/Node.js library for integrating with ClickFlare's conversion tracking API to upload online conversions programmatically.

## Features

- 🚀 Upload single or multiple conversions via S2S postback
- 📊 Format batch conversions for CSV upload
- 🔧 Full TypeScript support with type definitions
- ⚡ Async/await API with Promise support
- 🛡️ Built-in error handling and validation
- 🔌 Easy configuration via environment variables

## Installation

```bash
npm install
```

## Configuration

1. Copy the example environment file:

```bash
cp .env.example .env
```

2. Edit `.env` and set your ClickFlare tracker domain:

```env
CLICKFLARE_TRACKER_DOMAIN=tracker.yourdomain.com
CLICKFLARE_USE_HTTPS=true
CLICKFLARE_TIMEOUT=10000
```

## Usage

### Basic Example

```typescript
import { ClickFlareClient, Conversion } from './src';

// Initialize the client
const client = new ClickFlareClient({
  trackerDomain: 'tracker.yourdomain.com',
  useHttps: true,
  timeout: 10000,
});

// Upload a single conversion
const conversion: Conversion = {
  clickId: 'abc123def456',
  conversionType: 'sale',
  payout: 29.99,
  transactionId: 'ORDER-12345',
  timestamp: new Date().toISOString(),
  customParams: {
    param1: 'custom_value',
  },
};

const result = await client.uploadConversion(conversion);
console.log(result);
```

### Upload Multiple Conversions

```typescript
const conversions: Conversion[] = [
  {
    clickId: 'click_id_001',
    conversionType: 'sale',
    payout: 49.99,
    transactionId: 'TXN-001',
  },
  {
    clickId: 'click_id_002',
    conversionType: 'lead',
    payout: 5.00,
    transactionId: 'TXN-002',
  },
];

const results = await client.uploadConversions(conversions);
```

### Format Batch Conversions for CSV

```typescript
const batchConversions = [
  {
    clickId: 'click_001',
    payout: 29.99,
    transactionId: 'ORDER-001',
    conversionType: 'sale',
    timestamp: Date.now(),
  },
];

const csvData = client.formatBatchConversions(batchConversions);
console.log(csvData);
// Output: click_001, 29.99, ORDER-001, sale, 1234567890
```

## API Reference

### ClickFlareClient

#### Constructor

```typescript
new ClickFlareClient(config: ClickFlareConfig)
```

**Parameters:**
- `trackerDomain` (string, required): Your ClickFlare tracker domain
- `useHttps` (boolean, optional): Use HTTPS protocol (default: true)
- `timeout` (number, optional): Request timeout in ms (default: 10000)

#### Methods

##### uploadConversion(conversion: Conversion)

Upload a single conversion to ClickFlare.

**Returns:** `Promise<ConversionResponse>`

##### uploadConversions(conversions: Conversion[])

Upload multiple conversions sequentially.

**Returns:** `Promise<ConversionResponse[]>`

##### formatBatchConversions(conversions: BatchConversion[])

Format conversions to CSV for manual upload.

**Returns:** `string`

##### testConnection()

Test the connection to your ClickFlare tracker.

**Returns:** `Promise<boolean>`

### Types

#### Conversion

```typescript
interface Conversion {
  clickId: string;              // Required: Unique click ID from ClickFlare
  conversionType: string;       // Required: Conversion type (e.g., 'sale', 'lead')
  payout?: number;              // Optional: Revenue amount
  transactionId?: string;       // Optional: Unique transaction ID
  timestamp?: string;           // Optional: ISO 8601 timestamp
  customParams?: Record<string, string | number>; // Optional: Custom parameters
}
```

#### ConversionResponse

```typescript
interface ConversionResponse {
  success: boolean;
  message?: string;
  data?: any;
}
```

## How It Works

This integration uses ClickFlare's server-to-server (S2S) postback method for conversion tracking:

1. **GET Request**: Sends conversion data via GET request to your ClickFlare tracker
2. **Endpoint**: `https://your-tracker-domain.com/cf/cv`
3. **Parameters**:
   - `click_id`: The unique click ID from ClickFlare
   - `ct`: Conversion type
   - `payout`: Revenue amount (optional)
   - `transaction_id`: Unique transaction ID (optional)
   - `timestamp`: Conversion timestamp (optional)
   - Custom parameters (param1-param20)

## Error Handling

The client includes built-in error handling:

```typescript
const result = await client.uploadConversion(conversion);

if (result.success) {
  console.log('Conversion uploaded successfully');
} else {
  console.error('Failed to upload:', result.message);
}
```

## Best Practices

1. **Click ID**: Always use the actual click ID generated by ClickFlare (passed via `{cf_click_id}` token)
2. **Timestamp**: If not provided, ClickFlare uses the upload time
3. **Payout**: Should be a numeric value without currency symbols
4. **Conversion Type**: Use consistent naming for your conversion types
5. **Error Handling**: Always check the `success` field in responses
